Foto Profil

Foto ini akan muncul di Hero Section dan About Section. Disarankan rasio 3:4 (portrait), minimal 600×800px.

Drag & drop foto ke sini, atau klik untuk pilih

JPG, PNG, WEBP — Maks. 5MB

File akan disimpan sebagai assets/images/profile.jpg — rename file Anda sesuai nama tersebut dan pindahkan ke folder.

Gambar Project

Upload gambar untuk tiap project. Disarankan rasio 16:9 atau 4:3.

Drag & drop beberapa gambar sekaligus, atau klik untuk pilih

Cara mengganti gambar project:
1. Rename file Anda menjadi project-1.jpg, project-2.jpg, dst.
2. Pindahkan file ke folder assets/images/
3. Nama file harus sama persis dengan yang ada di HTML
